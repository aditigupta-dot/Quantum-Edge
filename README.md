# Quantum Quest

**Quantum Quest** is a learning project where I practiced Python and backend development. I wanted to build something with a backend server and a simple frontend that shows data, so I made this.

This project demonstrates basic backend-frontend integration, API creation, and data visualization for optimization experiments.

---

## Project overview

This project helped me learn how to:
- Build a backend server in Python
- Create an API that serves data
- Connect a frontend to a backend
- Organize code so it's easy to follow

---

## What it does

- **Backend server** built with Python and FastAPI to handle requests
- **Simple frontend dashboard** to display results from the backend
- **Optimization experiments** with finance-related ideas (learning project)

## Tech stack

- **Python** - Main language
- **FastAPI** - For the backend API
- **HTML, CSS, JavaScript** - For the frontend

## Getting started

### Prerequisites
- Python 3.11 or higher
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/quantum-quest.git
   cd quantum-quest
   ```

2. Create and activate a virtual environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Run the backend server:
   ```powershell
   uvicorn backend.main:app --reload
   ```

5. Open `frontend/index.html` in your browser to see the frontend.

---

## Usage

- Start the backend server as above.
- Open the frontend in a browser.
- The frontend interacts with the backend API to display data.
